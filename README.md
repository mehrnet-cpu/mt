# mehditanekar.ir — پیش‌نمایش آنلاین با GitHub Pages

ساده‌ترین راه انتشار، بدون FTP و بدون سکرت.

## راه‌اندازی (یک‌بار، دو دقیقه)

۱. فایل‌های این پوشه (`index.html`, `assets/`, `.nojekyll`) را در ریشه ریپازیتوری `mehrnet-cpu/mt` روی شاخه `main` قرار دهید.
۲. در گیت‌هاب: **Settings → Pages**
۳. زیر «Build and deployment» → Source را روی **Deploy from a branch** بگذارید، شاخه **main** و پوشه **/(root)** را انتخاب و **Save** کنید.
۴. بعد از حدود یک دقیقه، آدرس سایت در همان صفحه ظاهر می‌شود: `https://mehrnet-cpu.github.io/mt/`

از این به بعد با هر پوش روی `main`، همین آدرس خودکار به‌روز می‌شود — چیزی برای تنظیم کردن نیست.

## اتصال به دامنه اصلی (اختیاری، بعداً)

وقتی طراحی نهایی شد و خواستید روی `mehditanekar.ir` بنشیند، دو راه دارد:
- **ساب‌دامین** (مثل `new.mehditanekar.ir`): یک فایل `CNAME` با همین متن به ریپو اضافه می‌شود + یک رکورد CNAME در DNS دامنه به `mehrnet-cpu.github.io` اشاره می‌کند.
- **دامنه اصلی**: نیاز به هماهنگی با هاست وردپرس دارد (رکورد A دامنه به آی‌پی‌های گیت‌هاب پیجز).

بگویید کدام را می‌خواهید تا فایل‌های لازم را اضافه کنم.
