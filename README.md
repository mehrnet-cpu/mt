# mehditanekar.ir — پیش‌نمایش آنلاین با GitHub Pages

ساده‌ترین راه انتشار، بدون FTP و بدون سکرت.

## راه‌اندازی (یک‌بار، دو دقیقه)

۱. فایل‌های این پوشه (`index.html`, `assets/`, `.nojekyll`) را در ریشه ریپازیتوری `mehrnet-cpu/mt` روی شاخه `main` قرار دهید.
۲. در گیت‌هاب: **Settings → Pages**
۳. زیر «Build and deployment» → Source را روی **Deploy from a branch** بگذارید، شاخه **main** و پوشه **/(root)** را انتخاب و **Save** کنید.
۴. بعد از حدود یک دقیقه، آدرس سایت در همان صفحه ظاهر می‌شود: `https://mehrnet-cpu.github.io/mt/`

از این به بعد با هر پوش روی `main`، همین آدرس خودکار به‌روز می‌شود — چیزی برای تنظیم کردن نیست.

## اتصال به دامنه اصلی (root domain)

فایل `CNAME` (حاوی `mehditanekar.ir`) و `.nojekyll` از قبل در ریشهٔ ریپو آماده‌اند — با پوش شدن همین فایل، گیت‌هاب معمولاً فیلد «Custom domain» را در تنظیمات خودش پر می‌کند. با این حال، دو مرحلهٔ دستی و **خارج از این ریپو** باقی مانده که هیچ‌کدام از داخل ریپو قابل انجام نیست:

1. **در تنظیمات ریپازیتوری گیت‌هاب** (`Settings → Pages`): مطمئن شوید زیر «Custom domain» مقدار `mehditanekar.ir` ثبت شده (در صورت نیاز دستی وارد و Save کنید) و بعد از سبز شدن وضعیت DNS، گزینهٔ «Enforce HTTPS» را فعال کنید.
2. **در DNS دامنه** (پنل هاست/ثبت‌کنندهٔ دامنه، جایی که وردپرس فعلاً میزبانی می‌شود): رکوردهای A ریشهٔ دامنه (`@`) را به چهار آی‌پی گیت‌هاب پیجز تغییر دهید:
   - `185.199.108.153`
   - `185.199.109.153`
   - `185.199.110.153`
   - `185.199.111.153`

   این یعنی هاست وردپرس فعلی روی ریشهٔ دامنه دیگر پاسخ نمی‌دهد — چون رکورد A دامنه به گیت‌هاب پیجز اشاره می‌کند، نه به آی‌پی هاست وردپرس. اگر می‌خواهید وردپرس هم‌زمان در دسترس بماند، باید آن را روی یک ساب‌دامین (مثلاً `blog.mehditanekar.ir` یا مسیر دیگر) منتقل کنید یا این تغییر DNS را با هماهنگی کامل و در زمان مناسب انجام دهید.

انتشار انتظار خودکار روی آدرس موقت گیت‌هاب هم برقرار می‌ماند: `https://mehrnet-cpu.github.io/mt/`
